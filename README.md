# 퍼포먼스 마케터 포트폴리오

의존성 없는 HTML/CSS/JavaScript 원페이지 사이트입니다. 웹사이트 콘텐츠와 모양은 이 프로젝트의 소스 파일에서 수정할 수 있습니다.

## 콘텐츠 편집

- `content.js`: 이름, 소개, 핵심 수치, About, 프로젝트별 과제·실행·성과·인사이트, 경력, 자동화 내용, 이메일을 수정합니다. 입력값이 비어 있는 칸은 화면에도 비워 둡니다.
- `styles.css`: 색상, 타이포그래피, 간격, 모바일 레이아웃과 다크모드를 조정합니다.
- `app.js`: 프로젝트 펼침 동작, 타임라인 렌더링, 테마 전환 로직입니다.
- `index.html`: 페이지 구조와 메타데이터입니다.

프로젝트별 대시보드 이미지는 각 프로젝트 객체의 `image`에 경로를 넣으면 표시됩니다. 원본에 블러가 적용된 경우 이미지에 추가 효과를 더하지 않고 `imageCaption`에 `광고주 데이터 보호를 위해 수치 블러 처리`를 설정합니다. 원고가 제공된 뒤 `content.js`에 해당 원문만 옮기고, 이미지 파일을 프로젝트에 추가하면 됩니다.

## 로컬 미리보기

Python 3가 설치된 환경에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
python3 -m http.server 3000
```

`http://localhost:3000`에서 확인할 수 있습니다. 정적 배포용 파일은 `sh build.sh`로 `dist/`에 생성됩니다.
